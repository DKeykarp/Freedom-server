Сюда кладутся собранные установщики клиентов для компьютера и телефона. Сервер отдаёт их без авторизации,
а страница входа веб-версии показывает кнопки «Скачать»:

  Freedom-Setup-<версия>.exe            Windows
  Freedom-<версия>-linux-<арх>.deb      Debian, Ubuntu, Mint
  Freedom-<версия>-linux-<арх>.rpm      Fedora, RHEL, openSUSE
  Freedom-<версия>-android.apk          Android (сборка: app/README или ./gradlew assembleRelease)

Имя должно начинаться с "Freedom-" или "Freedom_" (остальные файлы не отдаются). Если файлов одного типа
несколько, показывается самый свежий, а <версия> (два или три числа через точку, например 5.0 или 1.2.3)
разбирается из имени файла и сравнивается с версией, которую сообщает о себе клиент — так работает
уведомление «доступно обновление» в Android и десктоп-приложении. Как собрать десктоп-клиент:
desktop/README.md (или `npm run publish:local` в desktop/). Другой путь к папке: переменная окружения
CHAT_DOWNLOADS. Минимальную поддерживаемую версию клиента (если нужно принудительно потребовать обновление)
задают переменные MIN_CLIENT_VERSION_WINDOWS, MIN_CLIENT_VERSION_LINUX, MIN_CLIENT_VERSION_ANDROID.
