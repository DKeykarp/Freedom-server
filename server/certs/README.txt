Сюда кладутся файлы сертификата для https://contora.is-local.org (формат ZeroSSL/Sectigo):

  certificate.crt   сертификат сайта
  ca_bundle.crt     промежуточный сертификат (сервер отдаёт его вместе с сертификатом сайта)
  private.key       закрытый ключ (без пароля)

Закрытый ключ никуда не публикуйте и не коммитьте: файлы в этой папке исключены через .gitignore.
Права: chmod 600 private.key. Проверка без запуска сервера:  python serve.py --check
Продление: замените три файла и перезапустите сервер (цепочка fullchain.pem собирается заново при каждом запуске).
